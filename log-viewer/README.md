# Logger Viewer(ログビューワー)

ESP32 が SD カードに記録した CSV(ルート README の「SD log」参照)を、ローカルで開いて地図の上で再生します。
Node.js だけで動き、依存パッケージはありません(Leaflet は `vendor/` に同梱)。

```sh
cd log-viewer
mise run start            # または: node server.js [ログのディレクトリ] [PORT]
```

http://localhost:3000/ を開きます。CSV は `logs/` に置いてプルダウンから選ぶか、ブラウザにドロップ / 「ファイルを選択」で開けます。
`LOG_DIR=... PORT=... mise run start` でディレクトリとポートを変えられます。

## 画面

- **地図**: 走行軌跡を速度で色分け(青 → 緑 → 黄 → 赤)。水色の矢印が現在位置と向き。右上のボタンで地図を切り替えられます。
- **軌跡の細かさ**: 右パネルで 0.1〜25 Hz から選べます。既定は 2 Hz です。長いログ(1 時間で約 9 万点)を 25 Hz のまま描くと重くなるので、軽くしたいときは下げ、細かい走りを見たいときだけ上げてください。同じ速度帯が続く区間は 1 本の線にまとめています。
- **右パネル**: 速度、時刻(JST)、G(重力を引いた値)、加速度、方位、高度、GPS の状態、水平精度、ヨーレート、バッテリー。
- **下**: 再生 / 倍速(1〜30)、シークバー、速度と G のグラフ(クリック / ドラッグでシーク)。
- キー: スペース = 再生 / 停止、←→ = 5 秒移動(Shift で 30 秒)。

## 地図について

どれも無料・API キー不要です。

| 地図 | 備考 |
|---|---|
| OpenStreetMap(既定) | 個人利用の軽い使い方は可。大量アクセスは [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) 参照 |
| 地理院 標準地図 / 空中写真 | 国土地理院タイル。日本国内向け。[利用規約](https://maps.gsi.go.jp/development/ichiran.html) |

地図タイルの取得にはインターネット接続が必要です(ログの読み込みと再生はローカルで完結します)。

## ログの扱い

- 位置情報を含むため、`logs/` の CSV はコミットしません(`.gitignore`)。`logs/demo.csv` だけは合成データなので入っています。`node make-demo.js` で作り直せます。
- 3D FIX が取れていない行(`fix` が 3 以外、`hacc_m` が 100 m 以上)は軌跡に使いません。再生中は直前の有効な位置に留まります。起動直後のダミー行(`fix=87` など)は捨てます。
- **走行距離**: 速度(ドップラー)を時間で積分しています。位置の差を足すと、停止中の GPS のゆらぎが距離として積もるためです。1 km/h 未満は停止とみなします。FIX が 1 秒より長く途切れた区間は、前後の位置の直線距離で埋めます。
- **G(重力を引いた値)**: ログ中の**静止区間**(3D FIX で 1 km/h 未満が 1.5 秒以上、揺れが小さい)ごとに「静止時の加速度 = 重力」を取り、各時刻は時間的に最も近い静止区間を基準にします。机の上で始めてから車に付けた場合や、走行中に取り付けがずれた場合も、次に停止した時点から合います。静止区間が 1 つも無いログでは G は出しません。
- **前後 / 左右**: GPS の速度変化(前後の加速度)と加速度センサーの向きを回帰して、車の前方向を推定します(取り付けの向きに依存しません)。前後は + = 加速、左右は + = 右向きの加速度(右コーナーで +)です。基準ベクトルが近い区間(約 8° 以内)は同じ取り付けとみなして推定をまとめます。直進での加減速が足りないログでは分けず、合成 G だけ出します。G ボールは直近 1.5 秒の軌跡つきです。
